Administrator

A local account. You can add people or connect an identity provider later in Management.

The address people and the mobile app use to reach this server. Needed for sign-in links and device pairing.

Libraries

Paths as seen inside the container: the Compose file mounts your ebooks at /books, audiobooks at /audiobooks, and managed-import destinations at /library/ebooks and /library/audiobooks. "Adopt" never moves or renames files; only "Managed" roots are written to.

Metadata sources

OpenReads (bundled) talks to Open Library and Google Books for you. API keys are optional and raise rate limits.

Secrets backend

{{app_name}} asks Infisical for any credential the environment does not provide, and expands infisical://NAME references. See docs/SECRETS.md.

Acquisition (optional)

Add an indexer and a download client now, or leave these blank and add them later in Management.
